## 🚀 Как сохранить проект

### Способ 1: Копирование файлов вручную

1. **Создайте папку** `car-accounting` на вашем компьютере
2. **Скопируйте все файлы** из этого проекта в созданную папку
3. **Сохраните этот README.md** в корне проекта

### Способ 2: Использование Git (рекомендуется)

```bash
# 1. Создайте папку проекта
mkdir car-accounting
cd car-accounting

# 2. Инициализируйте Git
git init

# 3. Скопируйте все файлы проекта в эту папку

# 4. Создайте .gitignore
echo "node_modules/
dist/
.env
.env.local
*.log
.DS_Store" > .gitignore

# 5. Сделайте первый коммит
git add .
git commit -m "Initial commit: Car Accounting v2.0"

# 6. (Опционально) Создайте репозиторий на GitHub/GitLab
git remote add origin https://github.com/your-username/car-accounting.git
git push -u origin main
```

## 🔧 Как запустить проект локально

```bash
# 1. Перейдите в папку проекта
cd car-accounting

# 2. Установите зависимости
npm install

# 3. Запустите dev-сервер
npm run dev

# 4. Откройте браузер по адресу http://localhost:5173
```

## 📤 Как собрать production-версию

```bash
# Сборка для продакшена
npm run build

# Готовые файлы будут в папке dist/
# Их можно задеплоить на любой хостинг
```

## 🔄 Как продолжить работу с ИИ-ассистентом

Когда вы захотите продолжить работу над проектом:

1. **Откройте новый чат** с ИИ-ассистентом
2. **Скажите**: "Давай поработаем над проектом 'Учёт автомобилей v2.0'"
3. **Прикрепите файлы** или **скопируйте содержимое** ключевых файлов:
   - `src/App.tsx`
   - `src/components/*.tsx` (все компоненты)
   - `src/types.ts`
   - `src/store.tsx`
   - `package.json`

## 📋 Ключевые особенности проекта

- **React 18** + **TypeScript**
- **Tailwind CSS** для стилей
- **Vite** для сборки
- **localStorage** для хранения данных
- **Тёмная/светлая тема**
- **Адаптивный дизайн**
- **Экспорт/импорт данных** (JSON, Excel)
- **Система уведомлений** (тосты)

## 🎯 Основные вкладки приложения

1. **Данные автомобиля** - учёт ТС
2. **Другие услуги** - учёт дополнительных услуг
3. **Итоги** - сводная статистика
4. **Тарифы** - управление тарифами
5. **Статистика** - аналитика и отчёты
