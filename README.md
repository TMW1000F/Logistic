# Учёт автомобилей v2.0 - Серверная версия

## 🚀 Запуск приложения

### 1. Сборка фронтенда
```bash
npm run build
```

### 2. Запуск сервера
```bash
npm run server
```

Или одной командой (сборка + запуск):
```bash
npm start
```

Сервер будет доступен по адресу: **http://localhost:3001**

---

## 📡 API Endpoints

### Данные
- `GET /api/data` - Получить все данные
- `POST /api/data` - Обновить данные (с блокировкой)

### Блокировки
- `GET /api/lock` - Получить информацию о блокировке
- `POST /api/lock/release` - Освободить блокировку
- `POST /api/lock/extend` - Продлить блокировку

---

## 🔒 Система блокировок

Приложение использует систему блокировок для предотвращения одновременного редактирования данных несколькими пользователями.

### Как это работает:
1. При первом изменении данных клиент автоматически устанавливает блокировку
2. Блокировка действует **30 минут** и автоматически продлевается каждые 10 минут
3. Другие пользователи видят, кто заблокировал данные (имя компьютера)
4. При закрытии вкладки блокировка автоматически освобождается

### Информация о блокировке:
- **userId** - уникальный идентификатор пользователя (генерируется автоматически)
- **computerName** - определяется по User Agent (Windows PC / Mac / Linux)
- **lockedAt** - время установки блокировки
- **expiresAt** - время истечения блокировки

### Файлы:
- `data.json` - основные данные приложения
- `lock.json` - информация о текущей блокировке

---

## 🔄 Синхронизация данных

- Данные автоматически сохраняются на сервер через **2 секунды** после изменения (debounce)
- При ошибке сервера данные сохраняются в localStorage как резервная копия
- При загрузке приложения данные загружаются с сервера, если сервер недоступен - из localStorage

## 🆘 Решение проблем

### Ошибка "Не удалось загрузить данные с сервера"
- Проверьте, что сервер запущен (`npm run server`)
- Убедитесь, что порт 3001 не занят
- Проверьте CORS настройки в `server.js`

### Данные не сохраняются
- Проверьте права доступа к папке проекта
- Убедитесь, что файл `data.json` может быть создан
- Проверьте логи сервера в консоли

### Блокировка не снимается
- Удалите файл `lock.json` вручную
- Подождите 30 минут (автоматическое истечение)
- Перезапустите сервер
